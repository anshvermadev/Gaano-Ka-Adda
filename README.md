# Gaano Ka Adda (गानों का अड्डा) 🎵

> **The ultimate Indian music hangout spot** - Immersive, scenic Indian audio & era-based musical experiences spanning 90s Nostalgia, 2000s Hits, 2010s, and Gen-Z trends.

---

## 🌟 Experience Modules

- **Phase 1: ट्रैक्टर वाला (Tractor Waala)** - 90s Indian Village Nostalgia with authentic retro radio player, scenic rural background visuals, ambient atmospheric effects, interactive sound easter eggs, and active listeners heartbeat counter.
- **Future Phases**: Additional themed hangouts (Train Journeys, Monsoon Terraces, Chai Dhaba, Late Night Drives, 2000s College Romance, Gen-Z Lo-Fi).

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router, Turbopack)
- **Language**: TypeScript (`.ts`, `.tsx`)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion & Canvas Particle Engine
- **Audio & Media**: YouTube IFrame API Controller & Web Audio API Synth Engine
- **State & Realtime**: React Hooks & BroadcastChannel Active Tab Presence

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
