# Gaano Ka Adda (गानों का अड्डा) 🎵

> **The ultimate Indian music hangout spot** - Immersive, scenic Indian audio & era-based musical experiences spanning 90s Nostalgia, 2000s Hits, Highway Truck Vibes, and Gen-Z trends.

---

## 🌟 Experience Modules

- **Phase 1: ट्रैक्टर वाला (Tractor Waala - `/`)** - 90s Indian Village Nostalgia with authentic retro radio player, scenic rural background visuals, ambient atmospheric effects, interactive sound easter eggs, and active listeners heartbeat counter.
- **Phase 2: सदाबहार 2000s (Bollywood Romance - `/2000s`)** - 69 iconic Bollywood romantic classics from 90s to 2000s (DDLJ, KKHH, Mohabbatein, Fanaa, Veer-Zaara, Jab We Met, KHNH) with smooth playlist search and auto-scroll.
- **Phase 3: ट्रक वाला (Highway Express - `/truck`)** - 54 classic highway road trip anthems with dynamic video background (bg.mp4), interactive "हॉर्न ओके प्लीज़" horn easter egg (horn.mp3), rotating authentic truck shayari, and real-time highway presence counter.
- **Future Phases**: Additional themed hangouts (Train Journeys, Monsoon Terraces, Chai Dhaba, Late Night Drives, Gen-Z Lo-Fi).

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router, Turbopack)
- **Language**: TypeScript (`.ts`, `.tsx`)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion & Canvas Particle Engine
- **Audio & Media**: YouTube IFrame API Controller & Web Audio API Synth Engine
- **State & Realtime**: React Hooks & BroadcastChannel Active Tab Presence

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
- 90s Village Nostalgia: [http://localhost:3000](http://localhost:3000)
- 90s-2000s Romance: [http://localhost:3000/2000s](http://localhost:3000/2000s)
- Highway Truck Express: [http://localhost:3000/truck](http://localhost:3000/truck)

### 3. Production Build
```bash
npm run build
npm start
```
